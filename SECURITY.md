# Security

Flow2Repo runs in the browser: uploaded designs are read locally and never sent to a server. The preview renders each screen in a sandboxed iframe where the design's own scripts do not run.

If you find a way to break that isolation, to run code from an uploaded design inside the Flow2Repo page, or any other security issue, please **do not open a public issue**. Contact [MHD Laith ALAllaf on LinkedIn](https://www.linkedin.com/in/mhdlaithalallaf) with the details, and allow time for a fix before disclosing it.
